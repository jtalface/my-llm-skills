# Lavish Light — design primitives

Champagne / cream light sibling of Lavish Dark (DaisyUI luxury inverted). Same fonts and radii; espresso text, dark CTAs, gold accents.

**Preview:** [preview.png](preview.png)

## Vibe (one sentence)

A bright luxury product UI: warm paper surfaces, espresso type, gold highlights, and dark primary actions.

## Typography

Same as `lavish-dark`: Cormorant Garamond (display), DM Sans (UI), IBM Plex Mono (code).

| Token | Hex | Use |

| `--bg` | `#f7f0e6` | Warm paper |
| `--bg-elevated` | `#efe6d8` | Sidebar / chrome |
| `--bg-panel` | `#fffaf3` | Cards |
| `--line` | `#e0d2bc` | Borders |

| `--code` / `--brand-mark` | gold family | Readable on cream |

## Proportions / components

Identical structure to `lavish-dark` (`lv-*` classes). Only tokens change.

## Do

- Keep warm cream atmosphere (not stark `#fff`)
- Dark CTAs + gold secondary accents
- Same large radii as dark

## Don’t

- Cool gray SaaS light mode
- Neon primary colors
- Mixing lime-lab fonts into this pack
