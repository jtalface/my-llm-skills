# Ledger Dark — design primitives

Warm charcoal counterpart to the Ledger Light look. Same Instrument fonts, violet accent, inverted CTA (light fill on dark).

**Preview:** [preview.png](preview.png)

## Vibe (one sentence)

Dark warm paper-night UI: charcoal panels, cream type, violet accents, light primary CTAs.
